Job Description

專案經理（PM）

Project Manager — 統籌專案全生命週期，串聯大腦與手腳，解放老闆決策能量的核心角色

📍部門：運營管理部
📊匯報對象：執行長（CEO）/ 大 PM
🏷️職級：中階管理
📋參考框架：PMI · PMBOK Guide
📌

職務概述

專案經理（Project Manager，PM）是公司專案運作的核心協調者，負責從需求確認到交付完成的全生命週期管理。PM 扮演「大腦」角色——負責專案調度、跨部門溝通、資源分配與進度掌控；讓執行手腳依標準流程推進，同時向老闆提供高層次的專案健康度視圖，而非個別問題清單。PM 的核心價值在於：讓老闆被解放，讓執行者有方向，讓客戶感受到一致性與可信賴。

🎯

主要職責

規劃與啟動

  • 定義專案範疇、目標與交付物
  • 建立工作分解結構（WBS）
  • 制定時程、里程碑與甘特圖
  • 評估資源需求與預算框架

執行與監控

  • 主持定期專案會議（每專案 30 分鐘）
  • 追蹤進度、識別偏差並提出修正
  • 管理專案風險登錄表並啟動應急方案
  • 確保成員按標準流程與表單執行

跨部門溝通

  • 識別並盤點所有利害關係人
  • 定期發送專案狀態更新報告
  • 協調跨功能衝突，防止事項繞過 PM
  • 擔任客戶與內部團隊的主要接窗

收尾與複盤

  • 確認交付物符合品質審計標準
  • 取得利害關係人正式驗收確認
  • 組織專案複盤，沉澱改善建議
  • 更新標準流程與表單版本

資源與預算管理

  • 協調人力資源排班，避免超載
  • 監控實際支出 vs 預算差異
  • 在授權範圍內自主調配（5% 以內）
  • 超出授權及時向大 PM / 老闆升報

大 PM 角色（高階）

  • 統管公司所有進行中專案
  • 每月向老闆提交整體健康度報告
  • 跨專案資源衝突的最終仲裁者
  • 建立並維護公司專案管理方法論

核心職能要求

🗓️

計畫與組織

建立清晰時程、分解任務、管理甘特圖，讓複雜專案可視化

💬

溝通與影響力

清楚傳達進度與風險，能在無直接職權下推動跨部門協作

🧩

問題解決

快速識別根本原因，評估解決方案，做出有依據的判斷

⚠️

風險管理

主動偵測威脅，建立風險登錄表，啟動應急預案

🤝

利害關係人管理

識別、分析並維繫所有關鍵利害關係人的期待與信任

📊

數據與判斷力

用數字說話，以 KPI 追蹤健康度，判斷哪些事需升報

🏗️

流程設計

制定可重複使用的標準表單與 SOP，讓執行者有所遵循

🧠

策略思維

理解公司目標，確保專案推進方向與整體戰略一致

🔄

適應力

在需求變動、人員變動、時間壓力下保持執行穩定性

🌐

利害關係人矩陣

利害關係人 關係類型 影響程度 PM 的核心任務 溝通節奏
執行長 / 老闆 最終決策者 高 提供整體健康度視圖，僅在需要決策時升報 月報 / 異常即時
大 PM 直屬主管 高 資源衝突協調、跨專案優先序確認 週同步
執行團隊（手腳） 直接管理 高 分配任務、追蹤進度、培訓標準流程 每專案定期會議
客戶 / 外部委託方 需求提出者 高 確認範疇、管理期待、正式驗收確認 里程碑節點 / 月報
部門主管 資源提供者 中 協商人力支援，避免跨部門資源衝突 按需協調
財務 / 採購 支援部門 中 預算審核、合約確認、費用核銷 按需提交
品質 / 法務 稽核單位 一般 確保交付物符合審計標準與合規要求 收尾階段

績效指標（KPI）

時程管理
準時交付率
專案在計畫時程內完成的比例，目標 ≥ 90%
老闆解脫指數
老闆被拉入細節次數
每週老闆被拉進個別專案細節的次數，目標趨近 0
預算管理
預算達成率
實際支出 vs 核准預算的偏差率，目標控制在 ±5% 內
品質
客戶滿意度（CSAT）
交付物驗收滿意度，目標分數 ≥ 4.0 / 5.0
風險掌控
風險處理時效
從風險識別到啟動應對方案的平均時間，目標 ≤ 24hr
跨部門衝突
衝突自主解決率
不需升報老闆、PM 自主解決的跨部門衝突比例，目標 ≥ 80%
🎓

資格要求

學歷：大學（含）以上，商學、管理、資訊或相關科系為佳；同等工作經驗亦可考量

工作年資：具備 2 年以上專案執行或協調經驗；有擔任 PM 主導角色者優先

專業認證（加分）：PMP（PMI）、CAPM、Scrum Master（CSM）等專案管理認證；PMP 認證者薪資溢價平均 33%

工具能力：熟悉甘特圖工具（Asana、Monday.com、Notion、MS Project）；能製作清晰的一頁式報告

語言：中文溝通流暢為必要條件；英文讀寫能力為加分項（跨國客戶場景）

軟實力：主動承擔、抗壓性高、善於聆聽；能在無直接職權下推動他人協作完成任務

⚖️

決策授權邊界（建議填寫）

情境 PM 自主決定 需向大 PM / 老闆確認
調整專案內部排程 ✅ 是 —
改動預算 5% 以內 ✅ 是 —
調整執行成員日常任務 ✅ 是 —
更換執行成員（人事變動） — ✅ 需確認
客戶要求追加範疇 — ✅ 需確認
預算超支 5% 以上 — ✅ 需確認
終止專案 / 重大方向調整 — ✅ 需確認

* 此表建議由老闆與 PM 共同填妥後正式宣布，是 PM 制度能否落地的關鍵第一步。
